# Day Planner Neumorphic UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> **Teacher mode:** Shubh writes every test and every line of product code. Claude explains each step, gives the test cases in plain English (the names and assertions below), reviews Shubh's code, and runs setup commands. "Just write it" from Shubh overrides this for one request only.

**Goal:** Rebuild the Day Planner interface as an animated, interactive, neumorphic planner in a Teams personal tab, without changing features or data.

**Architecture:** First a set of small, tested building blocks in `src/ui/neu/` plus theme tokens, then the screens rebuilt from those blocks one at a time. The logic layer (`useTasks`, `useToday`, `src/domain`, `src/storage`, `src/auth`) is not touched.

**Tech Stack:** React 19, TypeScript, Vitest + RTL, `motion@13.5.1`, `@microsoft/teams-js` (already installed).

**Spec:** `docs/superpowers/specs/2026-10-17-neu-ui-design.md`

## Global Constraints
- Interface only. Never edit `src/domain`, `src/storage`, `src/scheduler`, `src/auth`, or `useTasks.ts` / `useToday.ts`.
- `motion` pinned exactly: `"motion": "13.5.1"` (no caret).
- Accent `#5B8DEF`. Light surface `#E6E9EF`, shadows `#ffffff` / `#c4c8d0`.
- `data-theme` on `<html>` takes only `light | dark | contrast`.
- Swipe threshold: 30% of the row width.
- Category label `youtube` → **Content**; the stored value stays `youtube`.
- Every swipe action also exists as a button. Reduced motion means fades only.
- **Existing tests are the contract.** If a step would edit, skip or delete an existing test, STOP and ask Shubh first, explaining why. Known cases are listed as approval gates (Tasks 2, 7, 8).
- TDD: red → green → refactor; one commit per task on `feat/neu-ui`.

## Review Focus
1. **Swipe vs scroll:** a mostly vertical drag on a row must scroll the list, not fire an action. Test: a drag of dx = 10px, dy = 80px calls no handler.
2. **Expanded row and keyboard:** Tab reaches every action button, and Esc collapses the row and returns focus to it. Test it in Task 5.
3. **Sheet closing with unsaved input:** Esc or a backdrop click while typing must not save half a task. Test: after Esc, `onSubmit` is never called.
4. **Theme outside Teams:** in a plain browser, TeamsJS fails, so the theme must fall back to `prefers-color-scheme` without an error. Test it in Task 2.
5. **Pending-save and sign-in banners** still render above the new layout. The existing TodayView tests cover this; keep them green.
